# Словарь интерфейса

Одно имя на одну сущность. Если в тексте появляется другое слово для того же, берём слово из этой страницы.

## План

План клиента: расписание тренировок, которое клиент видит у себя и которое тренер собирает в студии (профиль клиента). Не «программа».

Кнопка сохранения плана — «Сохранить план». Сохранение явное, без автосохранения.

## Правила генератора

Экран `/plan-rules`. Сколько тренировок в неделю и сколько упражнений в тренировке генератор ставит в новые планы. Не «настройки плана» и не «правила планов».

Наборы «Стандарт / Мягко / Интенсивно» только подставляют числа. Сохранение остаётся отдельной кнопкой «Сохранить правила».

## Каталог тренеров

Список тренеров, которых клиент может выбрать. Не «поиск тренеров».

Каталог упражнений — другая сущность. Его так и называем: «каталог упражнений». «Собрать из каталога» в студии плана означает каталог упражнений.

## Приглашение

Связь, которую тренер отправляет клиенту: постоянная ссылка, код или запись со статусом «приглашение». Не «инвайт».

## Видимость в каталоге

Включён ли тренер в каталог тренеров. Не «показывать в поиске» и не отдельное имя «видимость профиля».

Включено: «Вас видно в каталоге тренеров». Выключено: «Вас не видно в каталоге тренеров».
